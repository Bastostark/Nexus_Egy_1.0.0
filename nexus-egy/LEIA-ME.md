# Nexus Egy
Pasta `www/` = o sistema. Consoles: NES, SNES, N64, GB/GBC/GBA, DS, Mega Drive, Master System, Game Gear, PS1, PSP.
- Testar no PC sem instalar: `Iniciar-Nexus-Egy.bat` (precisa de Python).
- Instalador Windows e APK: o GitHub Actions gera sozinho (aba Actions → Artifacts).
- PSP só funciona no programa do PC. Wii, GameCube, PS2, Dreamcast, Switch etc. NÃO têm núcleo incluído.
